## 対応を確認したブロック

編集画面と公開プレビュー、保存時の検証:

- core/group
- core/paragraph
- core/heading
- core/columns
- core/column
- core/quote
- core/pullquote
- core/verse
- テスト専用の color／background／forced／custom ブロック

内蔵アダプターのうち core/post-content は実際の投稿本文ブロックとしての編集・描画を未検証です。一般の動的ブロックは PHP フィクスチャで確認しています。

## 配布と保存の方針

build/、includes/、docs/、languages/、実行に必要な vendor/ を ZIP に含めます。node_modules、テスト、開発用 Composer パッケージ、ローカル設定は含めません。配布先に Node.js は不要です。プラグイン有効化は開発環境で確認しています。ZIP の管理画面アップロードによる新規インストールは未検証です。

保存 HTML を変更しない設計です。実際にプラグインを停止・再有効化した後の保存操作、アンインストール操作は未検証です。属性を失わずに編集を続けたい場合は有効な状態で利用してください。停止中にブロックを編集・再保存すると、WordPress が未知属性を落とす可能性があります。

## 既知の制限・未検証項目

- Firefox、Safari／WebKit、Edge、タッチ端末、スクリーンリーダー実機は未検証です。
- キーボードの矢印キーは E2E で確認済みです。フォーカスの視認性、全操作の Tab 巡回は実装し、手動の支援技術検証は未実施です。
- サイトエディター、テンプレートパーツ、同期パターン、再利用可能ブロック、パターン内の編集は未検証です。
- テーマ固有の !important、疑似要素による背景、ブロック固有の内部背景は保証対象外です。
- 既存背景画像のデータ保持と宣言順は PHP で確認しています。既存の標準グラデーションとの組合せは未検証です。画像のサイズ・リピート等の組合せを含む全ケースの視覚比較は未実施です。
- 認識できない構造、複数ルート、解析できない HTML、未知の属性バージョンは背景を適用しません。
- 対応候補に含まれても、未登録の描画構造は UI に警告を表示して有効化を止めます。ボタン・カバー・メディアとテキスト等の追加アダプターは今後の課題です。
- wp_loaded より後に登録されたブロックは候補一覧に含みません。
- 開発用依存の npm audit には 58 件（high 1、moderate 38、low 19）が残っています。critical は 0 です。これらの Node.js パッケージは配布 ZIP に含みません。残る high はビルドツールの serialize-javascript の間接依存です。互換性未確認の強制更新は実施していません。
- wp-env 12 では旧 tests 環境設定の非推奨案内が出ます。既存の開発・テスト環境を保持するため旧設定を維持しています。

## 改善候補

1. コアの追加アダプターと実在するサードパーティー製ブロックの検証。
2. Firefox／WebKit／タッチ端末のテストを CI に追加。
3. サイトエディター・同期パターン・テーマ切替を含む互換性テスト。
4. ドラッグ操作の履歴のまとめ方と読み上げ操作の改善。
5. PHP／JS の小数端数処理の追加比較、PHPUnit 形式への統合。
6. 翻訳カタログの整備、開発ツールの依存監査の継続。
